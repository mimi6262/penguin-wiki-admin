# penguin-wiki-admin

`admin.penguinwiki.kr` 입구 전용 저장소입니다. 들어오면 위키 관리 화면(`https://penguinwiki.kr/admin/`)으로 바로 넘겨 줍니다.
관리 화면의 실제 코드는 [penguin-wiki](https://github.com/mimi6262/penguin-wiki) 저장소의 `admin/` 폴더에 있습니다.

- `index.html`, `404.html`: 같은 내용. 어떤 경로로 들어와도 경로·검색·#을 유지한 채 넘깁니다.
- `CNAME`: 이 저장소의 GitHub Pages 주소(`admin.penguinwiki.kr`).
